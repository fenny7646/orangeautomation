Project Architecture

Structure & Documentation

Everything you need to scale your automation workflows, add custom blueprints, and wire background tasks.

Project Organization

  • app/__init__.py — Application Factory Pattern (create_app())
  • app/routes/api.py — REST API endpoints (/api/*)
  • app/routes/main.py — View templates (/, /about)
  • config.py — Environment-specific configuration
  • run.py — Local development runner

Running the Server

Activate your virtual environment and start the development server:

.\venv\Scripts\Activate.ps1
python run.py

Adding New Blueprints

Create a new file in app/routes/ and register it inside app/__init__.py:

from app.routes.my_route import my_bp
app.register_blueprint(my_bp, url_prefix="/custom")
